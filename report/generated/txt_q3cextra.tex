Further reading of Tab. 14: Untrained encoders of the same widths show the same ordering (25.4\% < 38.6\% < 48.6\%), so the agreement across AE-16/128/1024 largely reflects bottleneck width, not what reconstruction training adds. The only comparison that holds width fixed (d = 1024) points the other way: the DAE reconstructs worse than AE-1024 (MSE 0.00422 vs 0.00217) yet its representation carries more class information (52.6\% vs 50.7\%). Better reconstruction is therefore not what makes a representation more informative about the class.
